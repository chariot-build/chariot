- Chariot assumes all its directories/files are on the same fs (like rootfs, store, workdirs, ledger).

- Runtime requires RootFS to have some directories/files exist:
    - /dev/tty (file)
    - /dev/random (file)
    - /dev/urandom (file)
    - /dev/null (file)
    - /dev/zero (file)
    - /dev/full (file)
    - /dev/pts (dir)
    - /dev/shm (dir)
    - /run (dir)
    - /tmp (dir)
    - /proc (dir)
    - /etc/resolv.conf (file)
- Core requires RootFS to have:
    - /chariot (dir)
- RootFS expects user:
    - root
        - group root
        - uid 0
        - gid 0
    - chariot
        - group chariot
        - uid 1000
        - gid 1000
